---
name: generate-image
description: Generate reusable photos, illustrations and backgrounds for presentations, documents and other image requests.
---

Use `image_generate` whenever a task needs a generated raster visual and the capability is available. Desktop Pengbao mode uses the unified server configuration without a separate API key or saved provider setup; custom providers use the saved configuration in Settings → Plugins → Image generation. Credentials remain on the host. Never ask for an API key in conversation. In Pengbao mode prompts are sent to Pengbao and its configured image service, and the backend saves generated images to the current account's cloud files in addition to the local workspace copy. Do not create a web chat or automatically delete cloud files.

1. Identify the image's purpose and placement. For PPT/Word, inspect the relevant document or template first. Carry its palette, art direction and whitespace needs into `style_context`, and reuse that style across the document.
2. Write a complete prompt: subject, composition, setting, lighting, palette and required details. Specify room for titles or captions where the document needs it. Keep readable document text as native text; use native editable objects for charts, tables, flowcharts and simple diagrams.
3. Choose the target `aspect_ratio` and `purpose`. If the user explicitly requests exact pixel dimensions, pass the optional `size` as `WIDTHxHEIGHT`; otherwise omit it and let the selected provider use its default. A 16:9 slide does not require a 16:9 image when the illustration occupies only part of the slide. The tool returns actual dimensions; use proportional scaling or an intentional crop, preserving the main subject.
4. Call `image_generate` once per needed visual using the selected provider. Pengbao selects its model and service configuration on the server; send `size` only for an explicit user dimension request, and otherwise let the server choose the canvas. `aspect_ratio` remains composition guidance when no exact size is requested. Report `model_selection: server-managed` without inventing an actual model name. A presentation or document may call it in parallel for multiple visuals. The Host applies workspace and deployment policy. The conversation displays the resulting PNG with click-to-enlarge preview. If an image-viewing tool is available, inspect the PNG before placing it; report visual findings only after viewing it. When the user asks to alter an image that `image_generate` or `image_edit` already produced, call `image_edit` with `source.kind: "generated"` and that result's `sha256`; do not generate an unrelated replacement. Reuse an existing suitable image instead of generating duplicates.
5. Insert the returned `workspace_path` into the PPT/Word workflow, then inspect the rendered document page. Keep visual assets linked to their purpose and reuse their paths across later edits. Return the document and any requested standalone image.

If the tool reports missing configuration, direct the user to Settings → Plugins → Image generation. Pengbao disabled, forbidden or expired-session errors require administrator enablement, permission or sign-in, not a provider API key; unavailable status can be refreshed. A timeout or cancellation may still leave a generated and charged image on the server, so do not promise remote cancellation or automatically retry generation. Never request an API key in conversation or place one in a document, prompt, sandbox command or source file. Respect tool approval, cancellation and workspace policy. Surface provider errors accurately; use a placeholder only when the user accepts one. Configuration validation checks the connection without submitting an image generation job; successful generation is established by an actual generated image.

For a provider rejection, report the returned HTTP status, error code, parameter and request ID when present. A rejected adapter-owned parameter requires a plugin correction; preserve those diagnostics for the developer. Change a prompt or aspect ratio only when the reported cause points to that input. Describe account access or quota issues when the tool explicitly reports that category. The settings card validates custom providers automatically on Save; saving Pengbao mode only stores the mode choice and does not run image generation or paid validation.
